# Política de segurança

## O que entra no escopo deste repositório

Este repositório reúne documentação, templates, Profiles, prompts e checks de segurança do Vibe Security Framework.

Se o problema estiver no próprio framework, ele faz parte deste escopo. Isso inclui, por exemplo, um check automatizado inseguro, um comando capaz de causar dano inesperado, um exemplo que exponha credenciais, um prompt que incentive uma ação destrutiva sem autorização ou qualquer comportamento que possa levar alguém a executar testes perigosos.

## Como relatar um problema

Quando o problema puder ser explorado ou envolver informação sensível, prefira um canal privado do mantenedor antes de publicar os detalhes.

Ao explicar o caso, inclua apenas o necessário para reproduzir e entender o problema.

## O que não deve ser enviado

Não envie segredos reais, tokens, senhas, chaves privadas, dados pessoais, dumps de produção, exploits contra sistemas de terceiros ou evidências que revelem infraestrutura sensível.

## Uso responsável

Este framework não dá autorização para testar sistemas que você não possui ou para os quais não recebeu permissão.

Testes destrutivos, carga ou DoS, ações em produção, testes contra terceiros e alterações irreversíveis precisam de autorização e planejamento adequados.

## Sobre as evidências

Se uma issue pública for necessária, sanitize os exemplos antes de publicar. A evidência deve mostrar o problema sem expor mais informação do que o necessário.
