# Referências

O baseline foi construído com apoio de referências públicas de segurança. Elas ajudam a orientar a evolução do framework e servem como ponto de consulta para temas específicos.

## OWASP

- OWASP Application Security Verification Standard (ASVS):
  https://owasp.org/projects/asvs/
- OWASP Top 10:
  https://owasp.org/www-project-top-ten/
- OWASP API Security Project:
  https://owasp.org/www-project-api-security/
- OWASP Mobile Application Security (MAS):
  https://mas.owasp.org/
- OWASP Cheat Sheet Series:
  https://cheatsheetseries.owasp.org/
- OWASP GenAI Security Project:
  https://genai.owasp.org/

## Como essas referências são usadas

Elas funcionam como material técnico de apoio e cross-reference.

O Vibe Security Framework não é um produto oficial da OWASP. A presença dessas referências também não representa certificação, endosso ou conformidade formal.

Para alegar conformidade com um padrão específico, é necessário escolher a versão, o perfil ou nível aplicável e verificar formalmente os requisitos daquele padrão.
